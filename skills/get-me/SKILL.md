---
name: get-me
description: Confirm the user's intent before acting. Use when the user asks to be understood first or when plausible interpretations would materially change the deliverable, scope, or expected behavior.
---

Restate the intended outcome in your own words so the user can spot a misunderstanding. Describe what they would see or be able to do, and preserve the constraints they care about. Use plain language and explain technical terms through their practical consequences.

Check facts you can establish from the available context. If you inferred a motive or preference that affects the result, make the assumption visible. When a decision is still open, explain how the plausible choices would change the outcome and ask about the one that matters first.

Once the intent is clear, give the user a concise understanding to confirm. A single restatement can suffice. If corrected, update the affected part. Begin execution only after the user confirms your understanding.
